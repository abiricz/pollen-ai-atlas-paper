# Option A: image-only classification

Option A trains image-only classifiers with a ViT-Small/DINOv2-LVD backbone and linear heads. It provides the image-only baseline for regional, all-region, and stain-normalized experiments.

## File index

| File | Purpose |
| --- | --- |
| `train_classifier.py` | Trains one configured image-only experiment from `../experiment_config.yaml`, with support for seeds, DDP, checkpointing, class balancing, and stain normalization. |
| `evaluate_classifier.py` | Evaluates trained checkpoints on TS1, TS2, and cross-region test sets; writes metrics and confusion matrices. |
| `train_all.sh` | Batch runner for experiments `1-5`, `6-10`, selected regions, or direct experiment names. |
| `eval_all.sh` | Batch runner for intra-region and cross-region evaluation. |

## Experiment names

| Selector | Experiments |
| --- | --- |
| `1-5` or `exp1-5` | `linear_probe_all`, `linear_probe_french`, `linear_probe_hungarian`, `linear_probe_swedish`, `linear_probe_mediterranean`. |
| `6-10`, `exp6-10`, or `stainnorm` | `linear_probe_french_stainnorm`, `linear_probe_hungarian_stainnorm`, `linear_probe_swedish_stainnorm`, `linear_probe_mediterranean_stainnorm`, `linear_probe_all_stainnorm`. |
| `1-10` or `all-experiments` | Runs both groups. |

## Usage

```bash
cd 04_evaluation/scripts/experiments/option_A
bash train_all.sh 1-5 --seeds 41,42,43,44,45
bash eval_all.sh 1-5 --seeds 41,42,43,44,45
bash train_all.sh 6-10 --seeds 41,42,43,44,45
bash eval_all.sh 6-10 --seeds 41,42,43,44,45
```

Experiments 6-10 read stain-normalization references from `data/04_evaluation/normalization/`, generated by `../data_preparation/compute_stainnorm_reference.sh`.
